## 질문

## 왜 이 주제인가 (팀이 씁니다)
팀이 이 주제를 고른 이유 한 문단.
- 20902 노유나 : 우연히 친구를 따라 안양의 동안구라는 곳을 가게 되었고, 생각보다 학원가가 많이 형성되어 있어서 놀랐다. 그래서 나는 사교육 밀집도에 따라 학업 성취도가 얼마나 많이 달라지는지 궁금해서
- 이 주제를 선정하였다.
- 20905 백다인 : 중학교를 다니며 평택과 안양에 있는 중학교를 다녀보게 되었었다. 그때, 안양과 평택이 학업 성취도가 많이 다르다는 것을 알게 되었고 안양이 학원이 더 많았다는 점에서 학업 성취도가 사교육의 영향을 받나 궁금해서 위 주제를 선정함.
